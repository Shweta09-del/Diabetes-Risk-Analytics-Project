# 🏥 Diabetes Risk Prediction - Data Analytics Project
**AICTE | IBM SkillsBuild Internship 2026 | BharatCares**

## 📌 Project Overview
This project analyzes a dataset of 50,000 patients to understand and predict diabetes risk based on various health and lifestyle factors. It includes Exploratory Data Analysis (EDA) and a fully interactive web dashboard.

## 🔗 Dataset Link
* **Source:** Kaggle
* **Link:** https://www.kaggle.com/datasets/

## 🛠️ Technologies Used
* **Programming:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn, Plotly
* **Web Dashboard:** Streamlit

## 📂 Files Included
1. `Shweta_Diabetes_project.ipynb` - Contains the core data analysis and visualizations.
2. `dashboard.py` - The Streamlit app for the interactive dashboard.
3. `requirements.txt` - List of required Python libraries.
4. `Shweta_Report.docx` - Detailed insights, methodology, and visualizations.

## 🚀 How to Run the Dashboard
1. Open the terminal and navigate to the project folder (`D:\Diabetes`).
2. Install the required dependencies: 
   `pip install -r requirements.txt`
3. Run the Streamlit app: 
   `streamlit run dashboard.py`
